# C 语言指针：从理解到面试

> **一句话定义**：指针是保存某个对象**内存地址**的变量；通过解引用运算符 `*`，可以间接访问该对象。
>
> **核心主线**：任何指针问题都可从 **类型、内存布局、生命周期、边界、所有权** 五个角度分析。

---

## 1. 指针概述与作用

### 1.1 先分清：值、地址与解引用

```c
int a = 10;
int *p = &a;       // p 保存 a 的地址

printf("%d\n", *p); // 10：访问 p 所指向的对象
*p = 20;            // 间接修改 a
```

| 写法 | 含义 | 通俗理解 |
|---|---|---|
| `a` | 对象本身（值） | 东西本身 |
| `&a` | `a` 的地址 | 东西的门牌号 |
| `p` | 指针变量中保存的地址 | 写着门牌号的纸条 |
| `*p` | `p` 指向地址处的对象 | 按门牌进屋拿东西 |
| `int *p` | `p` 是指向 `int` 的指针 | `p` 指向的对象类型是 `int` |

指针不只是“一个地址”。其**类型**决定：

- 解引用时按何种类型读取/写入；
- 指针加 1 时移动的步长；
- 编译器可以进行哪些类型检查。

```c
char *pc;  // pc + 1 通常移动 1 字节
int  *pi;  // pi + 1 通常移动 sizeof(int) 字节
```

### 1.2 指针有什么用

1. **修改调用者的数据**：函数传值不会改到实参；传地址可以。
2. **高效传递大对象**：传结构体/数组的地址，避免复制大量数据。
3. **遍历连续内存**：数组、字符串的底层访问。
4. **动态内存与数据结构**：链表、树、缓冲区、回调函数等。
5. **多返回值**：通过输出参数返回额外结果。

```c
void swap(int *x, int *y) {
    int tmp = *x;
    *x = *y;
    *y = tmp;
}

int a = 1, b = 2;
swap(&a, &b);       // 传入变量地址，交换才会生效
```

### 1.3 指针是否可用：高频工程与面试重点

“非空”不等于“可用”。一次解引用必须同时满足：**对象存在、访问未越界、权限允许、类型匹配**。

| 问题 | 示例 | 后果/处理 |
|---|---|---|
| 空指针 | `int *p = NULL;` | 不能解引用；使用前按接口约定判空 |
| 未初始化指针 | `int *p; *p = 1;` | 野指针，未定义行为 |
| 悬空指针 | `free(p)` 后继续用 | 对象已失效；不再访问，持有者置 `NULL` |
| 越界指针 | 访问 3 元素数组的 `a[3]` | 未定义行为 |
| 重复释放 | 对同一地址二次 `free` | 未定义行为；明确所有权 |

```c
int *bad(void) {
    int x = 1;
    return &x;      // 错：函数返回后 x 的生命周期结束
}

int *p = malloc(sizeof *p);
if (p != NULL) {
    *p = 42;
    free(p);
    p = NULL;       // 防止当前变量意外继续使用旧地址
}
```

> **面试表达**：指针最危险的不是语法，而是生命周期、边界和所有权不清。解引用前我会确认：它指向谁？对象还活着吗？范围合法吗？我有修改权限吗？

## 2. 指针的运算

设 `int a[5] = {10, 20, 30, 40, 50}; int *p = a;`。

| 表达式 | 结果 | 前提 |
|---|---|---|
| `p + n` / `p - n` | 前/后移动 `n` 个 `int` 元素 | 结果仍在同一数组内或其尾后位置 |
| `p[i]` | 等价于 `*(p + i)` | `i` 是有效下标 |
| `p2 - p1` | 两地址相差的元素数 | 二者属于同一数组（或尾后位置） |
| `p1 == p2` | 地址是否相等 | 可比较 |
| `p++` | 先使用原指针，再移动一元素 | 不得越界后解引用 |

```c
printf("%d\n", *(p + 2));       // 30
printf("%d\n", p[2]);           // 30
printf("%td\n", &a[4] - &a[1]); // 3，差值类型为 ptrdiff_t
```

### 三条边界规则

1. 只在**同一个数组对象**范围内做移动与相减。
2. 可以形成尾后指针，例如 `a + 5`，它可比较、可作循环终点，**不能解引用**。
3. 无关对象的指针相减或大小比较没有可移植意义，不要依赖它。

```c
for (int *it = a, *end = a + 5; it != end; ++it) {
    printf("%d ", *it);
}
```

### 容易看错的优先级

```c
*p++;     // *(p++)：取当前元素后，p 后移
(*p)++;   // p 不动，p 指向的值加 1
*++p;     // p 先后移，再取值
++*p;     // p 指向的值先加 1
```

**记忆**：后缀 `++` 比一元 `*` 优先级高。复杂表达式应主动加括号，别把可读性赌在优先级上。

## 3. 指针与一维数组

### 3.1 数组名不是指针，但经常转换为首元素指针

```c
int a[3] = {1, 2, 3};
int *p = a;          // 多数表达式中 a 转换为 &a[0]
```

`a[i]` 与 `*(a + i)` 等价；但数组与指针不是同一个概念。

| 对比 | 数组 `int a[3]` | 指针 `int *p` |
|---|---|---|
| 本质 | 连续元素组成的数组对象 | 保存地址的变量 |
| `sizeof` | 整个数组的字节数 | 指针变量自身的字节数 |
| 能否重新赋值 | `a = p;` 错 | `p = a;` 对 |
| 地址语义 | 多数表达式中转为首元素地址 | 自身保存地址值 |

> 特例提示：在 `sizeof a`、`&a` 等少数场景中，数组名不会退化为首元素指针。

### 3.2 数组传参会退化

以下函数声明在参数位置等价，形参本质都是 `int *`：

```c
void print1(int a[], size_t n);
void print2(int a[10], size_t n);
void print3(int *a, size_t n);
```

所以函数内 `sizeof(a)` 得到的是指针大小，而不是数组总大小。长度必须显式传入：

```c
void print_array(const int *a, size_t n) {
    if (a == NULL) return;     // 接口应明确 NULL 与 n 的约定
    for (size_t i = 0; i < n; ++i) {
        printf("%d ", a[i]);
    }
}

#define ARRAY_SIZE(x) (sizeof(x) / sizeof((x)[0]))
/* 只能用于当前作用域内真正的数组，不能传入指针 */
```

> **面试一句话**：数组作为函数实参时会退化为首元素指针，长度信息不会自动保留；健壮 API 必须显式传长度，或清楚约定结束标记。

## 4. 指针与二维数组：理解“行地址”

```c
int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
```

二维数组是“**2 个元素的数组**”，每个元素又是“**3 个 `int` 的数组**”，按行连续存储：

```text
a[0][0] a[0][1] a[0][2] | a[1][0] a[1][1] a[1][2]
```

| 表达式 | 类型/含义 |
|---|---|
| `a` | 多数表达式中转为 `int (*)[3]`，指向第 0 行 |
| `a + 1` | 指向第 1 行，跨过整行 `3 * sizeof(int)` |
| `a[0]` | 多数表达式中转为 `int *`，指向第 0 行首元素 |
| `&a[0]` | `int (*)[3]`，第 0 行的地址 |
| `&a[0][0]` | `int *`，首个元素地址 |
| `&a` | `int (*)[2][3]`，整个二维数组地址 |

因此 `*(*(a + i) + j)` 等价于 `a[i][j]`。

### 为什么形参必须知道列数

```c
void show3(int (*a)[3], size_t rows) {
    for (size_t i = 0; i < rows; ++i)
        for (size_t j = 0; j < 3; ++j)
            printf("%d ", a[i][j]);
}

/* C99 及以后可使用变长数组形参 */
void show(size_t rows, size_t cols, int a[rows][cols]);
```

编译器必须知道一行有几列，才知道 `a + 1` 应跳过多少字节。

| 类型 | 表示什么 | 内存布局 |
|---|---|---|
| `int (*p)[C]` | 指向一行 C 个 `int` 的数组 | 连续固定行宽 |
| `int **pp` | 指向 `int *` 的指针 | 首层是地址表，行可分散 |

```c
int matrix[2][3];
int **pp = (int **)matrix;    // 错误且危险：类型和布局不匹配
```

> **面试要点**：连续二维数组匹配的是数组指针 `int (*)[C]`，不是 `int **`。二者名字相近，内存布局完全不同。

## 5. 字符指针与字符串

### 5.1 C 字符串是什么

C 没有内建字符串类型；所谓字符串是以空字符 `\0` 结尾的 `char` 序列，长度不包含 `\0`。

```c
char s1[] = "hello";        // 字符数组副本，可修改
const char *s2 = "hello";   // 指向字符串字面量，不可通过 s2 修改
```

| 写法 | 行为 | 能否修改字符 |
|---|---|---|
| `char s[] = "hi";` | 创建字符数组 | 可以 |
| `const char *p = "hi";` | 指向字面量 | 不可以 |
| `char *p = "hi";` | 旧式且易误导 | 修改字面量是未定义行为 |

### 5.2 字符串安全规则

1. 必须给终止符 `\0` 预留空间；`char buf[5] = "hello";` 没有终止符空间。
2. `strlen`、`printf("%s")` 依赖合法终止符；未终止数据会越界读取。
3. 复制/格式化要传入目标容量，优先使用有边界的接口和清晰的终止策略。
4. 只读输入参数用 `const char *`，让接口契约可见。

```c
char buf[8];
snprintf(buf, sizeof buf, "%s", "hello"); // 至多写 7 个字符和 '\0'
```

## 6. 指针数组与数组指针

`[]` 的优先级高于 `*`；括号可以改变结合顺序。

```c
int *pa[4];      // 指针数组：pa 是 4 个 int* 组成的数组
int (*p)[4];     // 数组指针：p 指向“含 4 个 int 的数组”
```

| 概念 | 典型用途 | 直观理解 |
|---|---|---|
| 指针数组 `char *names[]` | 多个字符串、动态行表 | 数组里装地址 |
| 数组指针 `int (*p)[4]` | 二维数组按行遍历/传参 | 一个地址指向整行 |

```c
const char *names[] = {"Alice", "Bob", "Cindy"};
int a[2][4];
int (*row)[4] = a;            // row + 1 移到下一行
```

**速记**：先和变量名结合的部分决定它的主体。 `int *p[4]` 中 `p[4]` 先成立，所以 `p` 是数组；`int (*p)[4]` 中 `*p` 被括住，所以 `p` 是指针。

## 7. 多级指针

```c
int value = 7;
int *p = &value;
int **pp = &p;

**pp = 9;     // pp -> p -> value，最终修改 value
```

`int **pp` 表示“指向 `int *` 变量的指针”，并不天然等于二维数组。

### 典型应用：修改调用者的指针

函数若要改变调用者指针变量本身（例如分配内存、修改链表头），需要接收该指针变量的地址。

```c
int alloc_one_int(int **out) {
    if (out == NULL) return -1;
    *out = malloc(sizeof **out);
    if (*out == NULL) return -1;
    **out = 0;
    return 0;
}

int *p = NULL;
if (alloc_one_int(&p) == 0) {
    /* 使用 p */
    free(p);
    p = NULL;
}
```

> **接口设计原则**：只读数据优先用 `const T *`；仅当确实需要改“调用者的指针指向”时，才使用 `T **`。

## 8. `void *` 与 `const`

### 8.1 `void *`：通用对象指针

`void *` 能保存任意**对象指针**。在 C 中对象指针可隐式转为 `void *`，再转回原本的对象指针；但 `void` 没有具体类型和大小，故不可直接解引用或做标准指针算术。

```c
int x = 100;
void *vp = &x;
printf("%d\n", *(int *)vp);  // 转回正确类型后再解引用
```

| 结论 | 原因 |
|---|---|
| `*vp` 不合法 | 不知道读多少字节、如何解释 |
| `vp + 1` 不应写 | 标准 C 无法确定步长 |
| `malloc` 返回 `void *` | 返回未定类型存储；C 中通常无需强转 |
| 函数指针不等同于 `void *` | 标准 C 不保证可互转 |

```c
int *p = malloc(10 * sizeof *p); // C 中无需强转 malloc 的返回值
if (p == NULL) {
    /* 处理分配失败 */
}
```

### 8.2 `const`：到底保护谁

从变量名向左读；左边没有再向右读。

| 声明 | 能否改 `*p` | 能否改 `p` | 含义 |
|---|---:|---:|---|
| `const int *p` / `int const *p` | 否 | 是 | 指向常量的指针 |
| `int *const p` | 是 | 否 | 常量指针 |
| `const int *const p` | 否 | 否 | 指向常量的常量指针 |

```c
int x = 1, y = 2;
const int *p1 = &x;
// *p1 = 3;        // 错：不能通过 p1 改 x
p1 = &y;           // 对：p1 可改指向

int *const p2 = &x;
*p2 = 3;           // 对：可改 x
// p2 = &y;        // 错：p2 本身不可重新指向
```

> `const` 限制的是“能否通过当前指针修改”。它不意味着底层对象永远无法被其他非 `const` 别名修改。

## 9. 面试高频问答

### Q1：`NULL`、野指针、悬空指针有什么区别？

`NULL` 是明确的空指针值，判空后不解引用即可；野指针通常未初始化或来源非法；悬空指针曾有效，但对象已释放或离开作用域。后两者都不能解引用。

### Q2：为什么数组名不能赋值，函数里 `sizeof(a)` 又得不到数组大小？

数组名代表数组对象，不是可重新指向的普通指针变量。数组作为函数实参会退化为首元素指针，因此形参中的 `a` 是指针，`sizeof(a)` 得到的是指针大小；数组长度必须由接口传入。

### Q3：`int **` 与 `int [R][C]` 为什么不能互换？

连续二维数组按固定列宽连续排布，匹配 `int (*)[C]`；而 `int **` 指向的是 `int *` 地址表，每行可分散、长度也可不同。二者布局不同，强转会错误解释内存。

### Q4：如何快速区分 `const int *` 和 `int *const`？

`const` 在 `*` 左，保护数据；在 `*` 右，保护指针。口诀：**左数据，右指针**。

### Q5：为什么 `free` 后建议置 `NULL`？

`free` 不会清掉变量中旧地址；继续使用就是悬空指针。置空可减少当前变量误用，但无法修复其他别名，也不能替代明确的所有权规则。

### Q6：指针和引用（C++）有什么区别？

**C 语言没有引用。** 在 C++ 中，指针通常可为空、可改指向、需显式解引用；引用通常是对象别名，初始化后不可改绑定。无论哪种形式，都不能绕过对象生命周期和越界规则。

## 10. 复习清单与排错流程

### 一页复习清单

- [ ] 能区分 `p`、`&x`、`*p`，并画出指向关系。
- [ ] 知道 `p + 1` 按**所指类型大小**移动，且只能在同一数组范围内运算。
- [ ] 牢记：可形成尾后指针，**不能解引用**尾后指针。
- [ ] 能说出数组与指针差异：本质、`sizeof`、能否赋值。
- [ ] 能写二维数组形参：`int (*a)[COL]` 或 `int a[rows][cols]`。
- [ ] 不把连续二维数组强转成 `int **`。
- [ ] 字符串始终为 `\0` 留空间；字面量用 `const char *` 访问。
- [ ] 能区分指针数组 `T *a[N]` 与数组指针 `T (*p)[N]`。
- [ ] 明确何时需要 `T **`：要修改调用者的指针变量。
- [ ] 熟悉三种 `const` 指针声明。
- [ ] 每次解引用前问：**指向谁？还活着吗？能访问吗？越界吗？**

### 复杂指针题的通用解法

1. **找变量名**：从变量名向外看，先处理括号、`[]`、`()`。
2. **写类型**：给每个子表达式标注类型，而非只凭直觉。
3. **画图**：画对象、地址、指针变量、数组边界和生命周期。
4. **查契约**：谁分配、谁释放、长度从哪来、是否允许 `NULL`、能否修改。
5. **工具辅助**：开启 `-Wall -Wextra -Wpedantic`；调试阶段可用 AddressSanitizer 排查越界与 use-after-free。

## 11. 最终记忆框架

```text
指针 = 地址 + 类型 + 有效生命周期
        │       │          │
        │       │          └─ 非空不等于可用：对象存活、权限正确、未越界
        │       └─ 决定解引用方式与 +1 步长
        └─ & 取地址；* 按地址访问对象

数组：连续元素；传参退化；长度显式传
二维数组：连续“行”；形参需要列数；不是 int**
字符串：char 序列 + \0；字面量只读
多级指针：每多一级，多一次间接访问；改调用者指针用 T**
void*：保存对象地址，使用前转回具体类型
const：保护数据还是保护指针，取决于它修饰谁
```

> **面试收尾模板**：我会把指针问题拆成类型、布局、生命周期、边界和所有权五件事。类型决定如何解释地址，布局决定如何寻址，生命周期决定能否访问，边界决定访问范围，所有权决定谁负责释放。这样既能解释语法，也能规避工程中的内存错误。
