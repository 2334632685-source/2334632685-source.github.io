# C 语言运算符：面试表达与易错点

> **面试总述（30 秒）**：C 运算符的核心不只是优先级，更是**类型转换、求值顺序和副作用**。工程中应当用括号与拆分表达式消除歧义；重点规避有符号/无符号混算、移位及自增自减带来的未定义行为。

---

## 1. 普通运算符

### 1.1 算术、关系、逻辑、赋值

| 类别 | 运算符 | 关键结论 |
| --- | --- | --- |
| 算术 | `+ - * / %` | 整数除法向 **0 截断**；`%` 仅用于整数，余数与被除数同号。|
| 关系 | `< <= > >= == !=` | 表达式结果是 `int` 的 `0` 或 `1`；浮点数通常不能直接用 `==` 比较。|
| 逻辑 | `! && ||` | `0` 为假、非 `0` 为真，结果恒为 `0/1`。|
| 赋值 | `= += -= *= /= %= ...` | 复合赋值带隐式转换，如 `short s; s += 1;` 合法。|

```c
int a = -7 / 3;   // -2：向 0 截断
int b = -7 % 3;   // -1
int ok = (3 < 5); // 1
```

### 1.2 `&&` 与 `||`：短路求值

两者都从左向右求值：`A && B` 在 `A` 为假时不计算 `B`；`A || B` 在 `A` 为真时不计算 `B`。这是常用的防御式写法。

```c
if (p != NULL && p->len > 0) { /* p 可安全解引用 */ }
if (p == NULL || init(p) != 0) { /* 仅必要时调用 init */ }
```

**面试提醒**：短路只属于 `&&`、`||` 和 `?:`；`&`、`|` 是位运算，两个操作数都会被计算。

## 2. 位运算符

| 运算符         | 含义   |   常见用途   |
| ----------- | ---- | :------: |
| `&`         | 按位与  | 掩码、清零指定位 |
| \|          | 按位或  | 置位、合并标志位 |
| `^`         | 按位异或 | 翻转位、判奇偶  |
| `~`         | 按位取反 |  构造反掩码   |
| `<<` / `>>` | 左/右移 | 位字段、构造掩码 |

```c
unsigned int flags = 0;
flags |=  (1u << 3);       // 置第 3 位
flags &= ~(1u << 3);       // 清第 3 位
flags ^=  (1u << 3);       // 翻转第 3 位
int set = (flags & (1u << 3)) != 0; // 测试第 3 位
int odd = (x & 1) != 0;    // 判奇偶
```

### 高频坑与标准表达

1. **位运算不是逻辑运算**：`a & b` 返回按位结果，`a && b` 返回 `0/1` 且短路。
2. 位操作优先使用**无符号类型**。负数右移的结果由实现定义；有符号左移越界、或移位位数 `< 0`、`>= 类型位宽`，均可能是未定义行为。
3. `1 << 31` 可能有有符号溢出，写为 `1u << 31`，同时保证位数合法。
4. 语义要用括号写清：`(x & mask) == 0`，而不是 `x & mask == 0`。

**记忆**：`&` 留共同的 1，`|` 汇总所有的 1，`^` 相同为 0、不同为 1，`~` 全翻转。

## 3. `x++` 与 `++x`

- `++x`：先加 1，**表达式值为新值**。
- `x++`：先取旧值，后加 1，**表达式值为旧值**。

```c
int x = 3;
int a = ++x; // x = 4, a = 4
int b = x++; // x = 5, b = 4
```

单独成句时 `x++;` 与 `++x;` 效果相同；只有在表达式中才有区别。对基本类型，现代编译器通常不会产生性能差异，应按语义选择。

### 未定义行为（高频面试点）

不要在同一个表达式中，对同一标量对象进行多次修改，或在没有确定求值顺序时同时读写它：

```c
// int y = x++ + ++x; // 未定义行为：禁止
// f(i++, i++);      // 实参求值顺序未规定：禁止依赖结果
```

**工程做法**：一个表达式只保留一个副作用；必要时拆成多行，例如 `int old = x; x++;`。

## 4. 三目运算符 `?:`

```c
result = condition ? expr_true : expr_false;
```

- 先计算条件，两个分支只会计算**其中一个**。
- 适合简单的“二选一”；复杂业务分支使用 `if/else`，可读性更好。
- 从右向左结合：`a ? b : c ? d : e` 等价于 `a ? b : (c ? d : e)`。

```c
int abs_x = x >= 0 ? x : -x;
const char *name = p ? p : "default";
```

**面试表述**：`?:` 是 C 中唯一的三元运算符。它有短路特性，只执行被选中的分支；但两个分支的类型需要能按规则合并。

## 5. 逗号运算符

逗号运算符 `(E1, E2)`：先计算 `E1`、丢弃其值，再计算 `E2`；整个表达式的值和类型由 `E2` 决定，并且二者存在明确的顺序关系。

```c
for (int i = 0, j = n - 1; i < j; ++i, --j) {
    /* 同时向中间收缩 */
}
int y = (x += 2, x * 3); // 先修改 x，再把 x*3 赋给 y
```

**易混点**：`f(a, b)` 的逗号、`int a, b;` 的逗号是**分隔符**，不是逗号运算符。除 `for` 等清晰场景外，业务代码不宜滥用。

## 6. `sizeof` 运算符

`sizeof` 返回对象或类型占用的字节数，结果类型是 `size_t`（无符号整数类型）。它不是函数。

```c
int a[10];
size_t bytes = sizeof a;              // 整个数组字节数
size_t count = sizeof a / sizeof a[0]; // 10：数组未退化时适用
size_t type_size = sizeof(int);       // 类型大小
```

### 规则与陷阱

1. 对**非变长数组（VLA）**，`sizeof(expr)` 通常在编译期确定，`expr` 不被求值：`sizeof(i++)` 不会使 `i` 增加。
2. VLA 的 `sizeof` 可能在运行期求值，不能把“`sizeof` 永不求值”绝对化。
3. 数组传进函数会退化为指针，函数内 `sizeof(arr)` 得到的是指针大小，不是数组大小。
4. `sizeof("abc") == 4`，因为包括字符串末尾的 `\0`。
5. 打印 `size_t` 使用 `%zu`；分配内存推荐 `malloc(n * sizeof *ptr)`，类型变更时不易出错。

## 7. 优先级、结合性与求值顺序

### 7.1 必须区分的三个概念

| 概念 | 回答的问题 | 例子 |
| --- | --- | --- |
| 优先级 | **先结合谁** | `1 + 2 * 3` 是 `1 + (2 * 3)` |
| 结合性 | 同优先级如何分组 | `a = b = 0` 是 `a = (b = 0)` |
| 求值顺序 | **先执行谁** | `f() + g()` 的调用先后未规定 |

优先级和结合性只决定语法分组，**不保证**子表达式的实际执行先后。不要依赖函数参数、`+`、`*` 等操作数的求值顺序。

### 7.2 常用优先级（高 → 低）

1. 后缀：`[] () . -> x++ x--`
2. 一元：`++x --x ! ~ + - * & sizeof`
3. 乘法：`* / %`；加法：`+ -`；移位：`<< >>`
4. 关系：`< <= > >=`；相等：`== !=`
5. 位：`&` → `^` → `|`；逻辑：`&&` → `||`
6. 条件：`?:`；赋值：`= += ...`；逗号：`,`

**实战原则**：优先级表只用于读代码；写代码时用括号表达意图。

## 8. 面试速答清单

1. `i++` 和 `++i`：单独使用相同；作为表达式时，前者返回旧值，后者返回新值。
2. `&&` 和 `&`：前者逻辑运算、结果为 `0/1`、会短路；后者逐位运算、不短路。
3. `sizeof` 是函数吗：不是，是运算符；多数情况下不计算操作数，但 VLA 是例外。
4. 能用移位代替乘除 2 吗：无符号、范围明确时可以；有符号数及负数要谨慎，现代编译器通常会自行优化。
5. 如何避免优先级 bug：关键处加括号；避免在同一表达式叠加自增、函数调用和副作用。

> **一句话收尾**：写 C 表达式时，先保证行为有定义，再保证类型正确，最后才谈位级优化；清晰的括号和无副作用的拆分，比死记优先级表更重要。
